# Nokira's personal website

![Picture](assets/README-banner.png)

This is my personal website, inspired by MySpace, built with HTML, CSS and JavaScript.
If you want to see the blog's repo [click here](https://github.com/n0kira/blog.nokira.dev)

## Components:
- Home Page:
  > Get to know me more with all the info I put on there
- Photo Gallery:
  > Here I put all the pictures that I took and find good enough to share.
- Projects Gallery:
  > Here I showcase every single project I make, even if they aren't polished or even finished.
- Blog:
  > I post some stuff that I want to share, or random things.. 

## Why did I make this?

To be honest there is not a proper reason. I just thought that owning a real hosted website that anyone can visit was cool!
Also, you always learn by doing stuff, so why not create a personal website?

## Stack:

HTML - for structure
CSS - for styling
JavaScript - for rendering

## How to host locally:

1. Clone the repo:
```
git clone https://github.com/n0kira/nokira.dev
```

2. Navigate into the repo folder
```
cd nokira.github.io
```

3. Open index.html
